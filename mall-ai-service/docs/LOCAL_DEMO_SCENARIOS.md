# Build 19.1 本地演示场景库

这套场景只用于本地演示。它不会在容器启动时自动装载，也不会清空、重置或改写已有用户数据。

## 两个起点

- 未装载富场景：沿用原始本地数据；运营端在近 7/30 天可能显示“暂无足够数据”。这是“证据不足”分支，不是假装有趋势。
- 装载富场景：运行 `scripts/load-build19-1-demo-scenarios.ps1 -Confirm`。脚本只插入带 `AI-DEMO-19-1` 标识的记录，重复运行不会重复插入。

## 富场景覆盖

| 展示对象 | 可看到的真实本地数据形态 |
| --- | --- |
| 运营聚合 | 待审核、退货中、已完成、已拒绝等多种售后状态和多种规范原因 |
| 事件链路 | PENDING、PUBLISHING、PUBLISHED、FAILED 的 Outbox 分支，以及 DELIVERED 消费记录 |
| 人工事项 | `policy_insufficient` 与 `tool_failure` 两个最小化 CaseHandoff；不包含客户原话、订单号或身份信息 |
| 客户安全边界 | 用不同商城账号查询不属于自己的订单时，系统只要求核对订单号，不会建立运营事项 |

富场景的订单号和商品名均为明确的本地演示记录，不能当作生产业务数据。运营分析仍只读取聚合数值与最小化事项；它不会写订单、售后或 Outbox。
