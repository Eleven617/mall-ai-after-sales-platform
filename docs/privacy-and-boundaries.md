# 隐私、数据可见性与非目标

## 四类身份的数据边界

| 身份 | 可见数据 | 不可见数据 |
| --- | --- | --- |
| 消费者 | 本人的公开回答、来源名称、Java 事实卡、草案、申请和案件公开进度 | Token、内部 intent、完整 RAG 原文/chunk/分数、工具轨迹、Outbox、内部备注、他人数据 |
| 运营 | 最小 Handoff、7/30 天可信聚合、只读分析草稿 | 原始客户聊天、任意订单/地址/电话、Token、业务写入口、人工内部备注 |
| 质量开发者 | 合成 EvalCase、安全结果投影、Profile、RunManifest、审核状态 | 真实客户会话、生产订单、生产 Handoff、生产 Trace、Token、RAG 原文 |
| 人工售后处理人员 | 可领取或已领取的最小案件、允许字段、内部处理所需的最小投影 | 任意用户数据、完整模型上下文、运营功能、质量数据 |

## 反馈与会话删除

消费者反馈默认只有 `helpful/not_helpful`、闭集 `reasonCode`、同意标志与安全 response reference；不收集自由文本。删除会话时，FastAPI 会清除该会员且该会话关联的临时 response reference、反馈、候选和审核记录。仓库中独立维护、版本化且合成的 EvalCase 不包含客户会话引用，因此不属于此删除范围。

Trace、RunManifest 和 FeedbackCandidate 仅允许安全字段白名单。禁止输入、日志、页面或公开仓库携带 API Key、JWT、密码、完整聊天、订单号、地址、电话、RAG 原文、原始工具结果、模型思维链、数据库导出、Chroma 索引、模型权重或 Docker 卷。

## 非目标与非承诺

- 不接入真实支付、仓储、物流、维修或真实客户数据；未配置外部系统时显示待人工/待履约，不伪造成功。
- 不提供自动退款、自动赔付、自动审核、自动改政策或在线多模型路由。
- 不做 Agent Swarm、通用 Shell/SQL/MCP 代理、长期记忆、K8s、A2A、知识图谱、训练或微调。
- 本地 Compose、合成数据、单元测试和手工冒烟不构成生产部署、独立安全审计、生产 QPS、P95、SLA 或模型通用准确率的证明。

发现安全问题时请遵循 [SECURITY.md](../SECURITY.md)，报告中只使用最小的合成复现信息。
