# v3.0.4 展示采集修复与事后补采

日期：2026-09-22。该记录不修改第三批原始 Report、Ledger 或 Lock，也不包含账号、会话原值、订单号、Token、Prompt、reasoning 或原始工具载荷。

## 根因与修复

第三批安全日志证明 Chrome/CDP 启动、客户登录和页面导航均成功。失败发生在登录后的异步工作区初始化：前端自动创建并激活了一个空会话，覆盖采集器刚写入的第三批目标会话；随后 `GET /api/agent-tasks?session_id=...` 返回空数组，`.agent-task-card` 等待超时。Mongo 脱敏投影确认原任务仍存在，owner/session hash 一致，业务记录没有丢失。

采集器现在等待登录初始化完成并出现活动历史会话后，再绑定目标会话；刷新后验证持久化选择，随后等待目标任务卡。主链采集不再错误要求卡片必须显示“已完成”：第三批任务安全停留在 `executing`，而 Java 回查成功已由原批次业务断言独立证明。采集结果新增安全的阶段和枚举错误码，区分启动、会话绑定、页面就绪、截图和文件校验。GIF 编码器会将不同尺寸的区域帧放入统一白色画布，避免后续帧按首帧尺寸裁切。
