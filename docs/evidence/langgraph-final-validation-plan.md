# 统一图补充验收计划

2026-10-12 用户要求补齐真实模型、远程 CI 与完整回退测试。

- 真实模型：仅合成客户/订单，通过现有统一对话和 TaskGraph；验证问候、任务追问、政策插问、继续、确认卡边界、隔离及撤回。再验证主展示链的 Java 确认和状态回查。Prompt、模型与 RAG 参数不变，不以重复采样修饰失败。
- 可见性：只向已配置 Provider 发送合成输入和现有安全投影。不运行历史客户的模型后台队列，临时密码仅进程内生成，不输出原始对话/模型文本。
- 成本：独立账本共享硬上限 80 HTTP attempts、200,000 Token，单次预留 12,000；依赖原有失败关闭和对账机制。没有货币价格假设；模型步骤可能耗时数分钟。
- 失败：保留失败结果，停止后续模型场景，先离线定位；本次不无限重跑。收尾关闭 live auth、回到 deterministic。
- 回退：保留卷和新图领域记录，停止新入口，切旧镜像并在反向代理禁止变更及图任务接口；验证旧服务健康、只读 Java 查询、变更拒绝；再切回新镜像，核对新图记录和服务恢复。不是让旧执行器接管新图在途任务，也不清库。
- CI：仅在候选分支提交和推送本次迁移文件；不包含用户未跟踪研究稿，不合并 main。精确验证候选 SHA 的两个工作流，旧 SHA 结果不替代。
