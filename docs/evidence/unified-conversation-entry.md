## 2026-09-24 真实回归

验证对象为本机未提交工作区构建的 AI/Web 镜像，不是历史冻结 Runtime；通过 Nginx → FastAPI → Java 和真实 DeepSeek 执行。未运行离线替代模型或完整发布评测。

首轮 8 项通过：问候不创建任务、复杂请求自动追问、政策插话保留事项、补充订单后继续同一事项生成 Proposal、文字确认不提交、会话隔离、重新读取恢复事项、跨账号读取返回 404。

首轮 18 次 HTTP attempts 全部成功，31,946 tokens，未结算 0。撤回请求完成后，回归脚本误以为返回值仍有 action，产生 TypeError；实际接口撤回后清除待确认 action。按既有接口合同修正断言，没有改动 Runtime 来迁就测试。

针对撤回路径单独补测 3 项通过：提供订单直接生成方案、确认卡显式撤回清除 action、任务审计中无 action_committed。补测 6 次 HTTP attempts 全部成功，19,625 tokens，未结算 0。

合计真实模型 24 次请求成功、0 次失败、51,571 tokens。11 项断言来自上述两个执行范围，不宣称一次完整 11/11 发布套件。最初两次夹具准备在创建会话时因脚本使用非 UUID 被 422 拒绝，发生在模型调用之前；修正为 UUID 后才执行以上回归。合成账号与订单通过 Java API 创建，不记录凭据和业务标识。

Python 模块导入、Vue 类型检查与生产构建、AI/Web Docker 构建通过，当前 8 服务健康。浏览器连接器初始化失败，未完成浏览器交互验收；此处的会话恢复与隔离是 HTTP 断言，不是浏览器操作证明。

本轮未验证最终业务提交、故障恢复、全量模型质量或视觉交互，既有证据仍只适用于原版本。历史 Report/Ledger/Lock 未修改。后续学习与改造后再做整体展示验收。
