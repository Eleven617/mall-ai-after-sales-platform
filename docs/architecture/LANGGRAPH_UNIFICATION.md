## 边界与权威

ConversationGraph 处理一次会话交互；TaskGraph 独立推进一个任务。二者不共享检查点线程。Java 保持身份、归属、资格、业务状态和最终事务写入权威。模型、业务规则、Prompt 和 RAG 参数不因本次迁移改变。

| 数据 | 唯一权威 | 其他表示 |
|---|---|---|
| Java 身份、订单、案件、售后结果 | Java API/MySQL | 只读且有时效的 Artifact |
| 任务执行位置、等待类型、图版本 | TaskGraph Checkpoint | AgentTask.status 为展示投影 |
| Plan、Artifact、ContextPack、Proposal、确认哈希和提交凭据 | TaskStore | 图中只存引用和修订号 |
| 安全会话记忆 | ConversationGraph 的安全记忆写入接口 | 交接摘要读取同一投影，不另存一份消息 |
| Java 会话展示历史 | Java | 不回灌为模型原始历史 |
| 旧售后工作流待确认领域数据 | 现有领域服务 | 不进入图 State；迁移时旧未确认动作失效 |
| 锁 | Redis（测试用内存） | 锁不是执行位置、不是业务事实 |

原始消息、JWT、HTTP Client、Java 工具完整响应、RAG 原文均为请求内对象，不放入 State、configurable、metadata、Checkpoint 或错误文本。内部能力子图不持久化上述对象，外部 tracing 也不得采集它们。

## 线程、版本与并发

- 客户请求先经 Java 验证成员与会话归属。会话线程由已作用域化的会话键构造；任务线程由 owner_ref 和 task_ref 构造。浏览器不得提供 LangGraph thread_id/checkpoint_id。
- 线程带图主版本。请求只接受最新检查点；不提供时间旅行或任意 fork API。
- 任务执行锁覆盖继续、修改、确认、取消；TaskStore 使用修订号比较交换，过期持锁者不得覆盖新状态。
- 会话节点在读写记忆时使用短锁，任务运行使用独立锁。任务执行期间的政策插问不应推进或覆盖任务。
- 同一客户端 request_id 在一个会话内只接收一次，重用不同内容拒绝；未完成请求返回处理中或结果未知，不能重发业务动作。

## TaskGraph 节点合同

State 仅包含图版本、owner/task 引用、领域修订号、run 引用、计数、受控阶段和展示投影。模型决策及原始 Skill 参数保留在当前请求，不存检查点。

| 节点 | 输入/依赖 | 输出/失败行为 |
|---|---|---|
| prepare | 领域引用、当前新认证、请求内用户输入 | 校验版本/TTL/预算并发现 Skill；缺输入转等待 |
| decide | 现有模型上下文构造器 | 请求内结构化决策；调用前持久化预算消耗，失败阻塞 |
| validate | Schema、Catalog、Artifact、当前参数 | 服务端决定唯一下一节点；禁止写 Skill 直达 |
| read_skills | 已校验只读调用 | Artifact 领域保存，图仅保存修订号 |
| curate / critic | 已允许 Artifact 投影 | 复用原压缩、条件 Critic 和降级合同 |
| revise / spawn / propose / finish | 已校验决策 | 复用领域行为；子任务也使用 TaskGraph |
| publish | 已保存的领域记录 | 检查点展示投影；待补充或待确认转 interrupt |
| await_input | 仅安全等待类型与引用 | 无副作用；恢复后按显式操作分支 |
| confirm / amend | 新认证、当前 Proposal 版本、客户动作 | 现有领域验证、Java 幂等提交/对账；不从模型文字恢复确认 |

节点中断会从节点开头重跑。调用前消费预算并保存尝试状态；进程在外部调用中退出时不得盲目重发。无可恢复的请求内决策时，转安全等待，要求客户重新提供输入；Java 已提交或未知的动作只能先查原幂等请求。领域已写而检查点未写时通过领域修订重建投影，不重新提交。

## ConversationGraph 与能力网关

接收并去重 → 读取安全记忆和任务投影 → 路由 → 回答能力/任务派发/选择澄清/交接 → 安全记忆提交 → 结束。本图不等待任务的人类确认；TaskGraph 以独立线程暂停。

复用现有入口 Prompt、Intent 和各业务 Skill；原传统售后适配器只能作为图调用的能力，不能独立推进同一个 TaskGraph 任务。所有业务工具通过统一 Skill 网关，网关仍调用 Java 权限校验；只读与确认执行器分离。

安全记忆包括有限近期安全片段、角色、source ref/序号、事项范围、遗漏标志、修订号、到期时间。安全投影发生在任何持久化之前。旧原文和自由文本摘要不自动搬入新图；可迁移现有已审核安全交接片段。压缩失败保留有上限的已验证片段和遗漏标志，不退回原文拼接。

## 旧数据与回退

1. 不删除旧 TaskStore/Java 记录，不覆盖历史验证文件。
2. 缺图版本的旧任务只读可见；旧 awaiting_confirmation 不能在新图确认。经认证显式继续时保留事实索引、使旧卡失效、生成新图与新版本提案。confirmed/unknown 必须对账，不能按“重新开始”重发。
3. 部署前统计旧记录的状态/数量/最早到期时间，只取聚合，不读客户原文。
4. 切换不允许同一任务同时由旧执行器和新图执行。回退停止新任务推进，保留新图记录；旧版本不得接手新图未完成确认。Java 已提交结果保持原样。
5. 删除会话时清除该会话所有版本检查点及写入记录，先立删除标记防并发复活；任务/业务记录按独立保留规则处理。

## 已核实与保留边界

本机 Mongo 索引/TTL、跨进程检查点恢复、Redis 跨进程锁、旧记录聚合、AI 容器重启、Java 已写入后丢失响应的原请求对账已验证；模型边界使用脚本替身。浏览器和 Java 人工交接、售后确认路径亦有当前源码证据，见 [环境记录](../evidence/langgraph-migration-environment.md)。

旧镜像保留为 `mall-ai-langgraph-rollback:20261012`，已实际切换旧只读入口并恢复新镜像，前后领域/检查点内容哈希一致；没有两个执行器同时推进任务。真实模型仅执行有界功能冒烟，未重跑完整质量评测；生产备份恢复和 main 发布未执行。回退须关闭任务变更入口，不能直接让旧镜像接管新图在途任务。

## 验证与扩展

新增 Skill 必须先登记 Catalog 版本、输入/输出 Schema、角色、读写模式、预算、幂等与失败码；然后接入网关，提供正常/拒绝/超时合同。新增子图只接收最小安全引用，声明是否可重放与是否有持久状态；禁止独立保存另一份会话历史或客户凭证。新图版本需要兼容读取/拒绝策略和旧确认过渡测试。

保留矩阵及真实命令结果单独记录。框架单节点示例通过不能代替政策、查询、长任务、多任务选择、插问、继续、确认、修改、取消、人工交接、运营分析和重启/对账验收。
